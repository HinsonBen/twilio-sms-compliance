# Twilio A2P 10DLC Public Pages

These static pages are intended for the public-facing compliance information for a Twilio A2P 10DLC SMS campaign.

## Before publishing

Replace every placeholder:

- `[YOUR REGISTERED BRAND NAME]` — use the exact brand name registered in Twilio/TCR.
- `[DATE]` — use the date you publish the policy.
- `[SUPPORT EMAIL/PHONE]` — use a real support contact.
- `[BUSINESS ADDRESS OR CONTACT ADDRESS]` — use an appropriate real contact address.

Do not publish a real personal mobile number or other sensitive information.

Files:

- `index.html`
- `privacy.html`
- `terms.html`
- `sms-opt-in.html`

After publishing with GitHub Pages, use:

- `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/privacy.html`
- `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/terms.html`

in the Twilio A2P campaign registration form.
