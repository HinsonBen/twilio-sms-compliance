Trader CoPilot SMS Program

This site provides information about the SMS messaging program operated by Trader CoPilot.

Trader CoPilot uses SMS exclusively to deliver operational desk alerts to a single authorized recipient: the Trader CoPilot account owner/operator. SMS is not used for marketing, customer solicitation, order placement, or transactions.

How the Recipient Authorizes SMS

The account owner/operator explicitly authorizes their own personal mobile number by configuring it as the authorized SMS recipient in the Trader CoPilot application. Trader CoPilot sends SMS only to that configured number. There is no public sign-up, and messages are never sent to customers, the general public, or any other number. See SMS Authorization for details.

Program Information

  • Program: Trader CoPilot operational desk alerts.
  • Recipient: Only the account owner/operator's authorized mobile number.
  • Message frequency: Varies. Messages are sent only when an operational alert is triggered.
  • Cost: Message and data rates may apply.
  • Opt out: Reply STOP at any time to stop receiving messages.
  • Help: Reply HELP for help, or email hinsonben@gmail.com.
